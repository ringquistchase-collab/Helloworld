# Helloworld
Consent-gated peer-to-peer research network: authenticated, encrypted nodes (Ed25519/X25519/AES-256-GCM) mine signed blocks from real public research APIs (ClinicalTrials.gov, PubMed, ClinVar, NIH). Includes semantic search, a tamper-evident audit trail, and a verified cross-language protocol (Python, JS, Java, C++, Go, Ruby). MIT licensed
